문제 발견: 식재료가 아니라, 정보가 잊힌다

[12정과04-01] · 환경과 가정생활에서 찾은 해결 가능한 문제

일상에서 있을 법한 상황

보이지 않는 재료는 기억에서 사라진다.

장 본 식재료를 냉장고에 넣고 나면 어떤 재료가 있는지, 언제까지 관리해야 하는지 잊기 쉽습니다. 이미 있는 재료를 다시 사거나, 날짜를 뒤늦게 확인하는 상황이 생길 수 있습니다.

이는 프로젝트를 위한 가설적 문제 상황입니다. 실제 폐기량이나 개선 효과를 조사한 결과는 아닙니다.

정보과학적으로 다시 정의하기

“식재료 이름과 소비기한을 데이터로 저장하고, 날짜가 가까운 순서대로 보여 주면 어떨까?”

날짜 기억하기 → 데이터 저장
남은 기간 알아보기 → 날짜 차이 계산
먼저 확인할 재료 고르기 → 조건 분류·정렬

안전한 범위 설정: 이 프로그램은 입력한 표시 날짜로 관리 순서를 제안할 뿐, 음식의 안전성이나 실제 섭취 가능 여부를 판단하지 않습니다. 기한이 지난 항목은 ‘우선 사용’에서 제외합니다. 보관 상태·개봉 여부·제품 표시를 확인하고, 날짜가 남았다는 이유만으로 먹어도 된다고 판단하지 마세요.
02

요구 분석: 무엇을 입력하고, 무엇을 보여 줄까?

[12정과04-02] · 사용자·입력·출력·제한 조건의 연결

프로젝트 요구사항
분석 항목이 프로젝트의 구체적 정의
사용자집에서 식재료를 구매·보관하는 가족 또는 자취생
입력식재료 이름, 수량·단위, 보관 장소, 표시된 소비기한 / 분석 기준일, 임박 기준 일수
처리입력 검증 → 기준일과 소비기한의 날짜 차이 계산 → 네 상태 분류 → 소비기한 오름차순 정렬
출력식재료별 남은 일수·상태, 상태별 건수, 오늘·임박 항목 중 우선 확인할 재료 최대 3개
제한 조건100건 이하 / 이름 1~40자 / 수량 1~999 정수 / 날짜 1900~2100년 / 개인정보·사진 미수집 / 웹 푸시·식품 안전 판정 제외
성공 기준정해진 12개 정상·경계·예외 테스트 통과. 100건의 입력을 정렬·분류해 누락 없이 표시. 실행 환경을 함께 기록하며 성능은 직접 측정.

실제 환경 효과는 별도 확인이 필요합니다. 예를 들어 사용 전후 1주 동안의 폐기 식재료 건수를 기록하되, 이 페이지에서는 절감 효과를 입증했다고 주장하지 않습니다.

선택근거

date 날짜 연산문자열의 날짜 일부만 빼지 않고 실제 날짜 차이를 구한다. 월말·연말·윤년의 경계를 처리할 수 있다.
if / elif 조건 분류남은 일수 < 0 → 경과 / = 0 → 오늘 / 1~기준일수 → 임박 / 그 이상 → 여유.
안정 정렬소비기한 오름차순으로 보여 준다. YYYY-MM-DD로 검증된 날짜 문자열은 사전식 순서가 날짜순과 일치한다. 같은 날짜면 입력 순서를 유지한다.
순차 탐색이름 검색은 100건 이하의 목록을 한 번씩 검사한다. 부분 문자열 검색이므로 이진 탐색을 적용하지 않는다.
복잡도검증·분류 O(n), 정렬 최악 O(n log n), 목록·검색 O(n). 출력용 보조 공간 O(n).

항목이 프로젝트의 계획
① 문제 상황가정에서 식재료 목록과 표시된 소비기한을 잊어 중복 구매하거나 기한 경과를 뒤늦게 확인한다. 사용자·제약은 02절과 같다.
② 해결 목표100건 이하의 식재료를 누락 없이 네 상태로 분류하고 날짜순으로 제공한다. 오늘·임박 중 최대 3건을 우선 확인 목록에 표시한다. 준비된 테스트 12개가 모두 통과해야 한다.
③ 입력 데이터이름, 수량, 단위, 보관 장소, 소비기한 / 분석 기준일과 임박 기준. 개인 식별 정보는 필요하지 않다.
④ 출력 결과상태별 등록 건수, 날짜순 전체 목록, 우선 확인 목록, 잘못된 입력 메시지, 테스트 결과, TXT 결과 파일.
⑤ 핵심 기능등록·삭제 / 검증 / 날짜 차이 계산 / 네 상태 분류 / 안정 정렬 / 검색·필터 / 테스트·내려받기.
⑥ 자료 구조·알고리즘리스트·딕셔너리, date 연산, 조건 분기, 안정 정렬, 부분 문자열 순차 탐색. 구체적 선택 근거는 04절에 제시했다.
⑦ 테스트 기준06절의 12개 테스트와 실제 등록·삭제·검색·파일 저장을 확인한다. 날짜 경계와 잘못된 입력도 검증한다. Python 첫 로딩 시간과 분석 시간은 분리해 기록한다.
⑧ 역할·일정·산출물분석 담당: 문제·요구사항·예상 결과 / 구현 담당: Python 처리·HTML 연결 / 검증 담당: 테스트·발표 정리. 개인 프로젝트라면 순서대로 맡는다. 산출물은 이 HTML, Python 소스, 테스트 기록, 현재 결과 TXT이다.
