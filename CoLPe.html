Opening Remarks — Mathematics, Science, and Computer Science

“The arc of a basketball is a mathematical function, and the forces shaping that arc follow the laws of science. Computer science lets us express those principles in code, test them, and make predictions. One person could build everything, but four people contributing different expertise can tackle a bigger challenge. Today, each of you will design a library, and together you will connect four contributions into one program.”

Essential question: How can we integrate code written independently by four people into one reliable program?

01 · Understanding Concepts

Core Concepts

ModuleA file containing Python definitions and statements. For example, geometry.py can contain functions for geometric calculations.

LibraryA collection of modules and features organized for reuse in other programs.

ClassA blueprint defining an object’s stored state (attributes) and behavior (methods).

MethodA function defined inside a class that implements an object’s behavior.

02 · Collaborative Design

Team Interface Agreement

Before development begins, agree as a team on file names, class names, method names, parameters, return values, units, and error-handling rules.

Do not change another team member’s file without agreement. Test each module independently before running the integrated application.

03 · Learning Outcomes

Learning Objectives

  1. Divide a real-world problem into four distinct responsibilities.
  2. Create Python modules containing object-oriented classes.
  3. import to integrate four modules into one program.
  4. Perform unit and integration tests, and correct errors.
  5. Explain role assignments and the collaboration process with evidence.

Five Collaborative Projects

Each project consists of four student-owned .py files and main.py. Save all files in the same folder and run python main.py. You can copy individual files or download a ZIP of the complete project.

Closing Remarks — Humanities, Philosophy, Music, and Art

“Music comes alive when instruments share a score while preserving their individual voices. A painting becomes beautiful when line, color, light, and space work in harmony. Philosophy asks whether the whole is merely the sum of its parts, while the humanities explore how different people create meaning together. Our four libraries are small works reflecting individual ideas. By honoring shared agreements and connecting them, we transform separate code into a collective creation.”

Reflection questions: Was my module’s responsibility clear? Did I provide an interface that others could understand? How did our joint work improve on what we could have made individually?

Assessment and Results

Five project questions + ten true/false diagnostics + ten formative questions = 25 questions, four points each (100 total). For each multiple-choice question, choose the option containing all three true statements.
