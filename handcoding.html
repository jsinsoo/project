3. 코드 구현

Python 함수와 모듈, 입력 검증, 실행 결과

오류 유형별 발생 횟수를 계산하여 빈도순으로 출력한다.

from collections import Counter

errors = [
    "반복문", "리스트", "반복문",
    "재귀함수", "함수", "리스트",
    "반복문", "재귀함수"
]

def analyze_errors(data):
    if not data:
        return []
    counts = Counter(data)
    return sorted(counts.items(), key=lambda x: (-x[1], x[0]))

result = analyze_errors(errors)
for topic, count in result:
    print(f"{topic}: {count}회")

예상 출력

반복문: 3회
리스트: 2회
재귀함수: 2회
함수: 1회

반복문을 우선 학습하고 리스트와 재귀함수를 다음 학습 대상으로 정한다.

4. 효율성 분석

시간·공간 복잡도, 데이터 규모별 성능

오답 기록 n개, 오류 유형 k개일 때 집계는 O(n), 정렬은 O(k log k)이므로 전체 시간 복잡도는 O(n + k log k), 추가 공간 복잡도는 O(k)이다. 기록이 많아질수록 자동 집계가 반복적인 수작업을 줄여 준다.
