결과뿐 아니라, 경로를 발견하는 과정을 살펴보세요.

BFS / BREADTH-FIRST SEARCH

가까운 칸부터, 너비 우선 탐색

큐(선입선출)에 이웃을 넣고 먼저 들어온 칸부터 꺼냅니다. 1수, 2수, 3수 거리 순서로 탐색하므로, 한 번의 이동 비용이 모두 1인 이 앱에서는 최소 이동 횟수를 보장합니다.

queue ← [start]
while queue is not empty:
  current ← dequeue(queue)
  if current == goal: return 경로 복원
  미발견 이웃을 발견 표시하고 enqueue
DFS / DEPTH-FIRST SEARCH

새로 찾은 칸부터, 깊이 우선 탐색

스택(후입선출)에서 최근에 들어온 칸을 먼저 꺼내 탐색합니다. 목표를 일찍 찾을 수도 있지만, 최단 경로는 보장하지 않습니다. 어느 쪽의 방문 수가 적은지는 배치에 따라 다릅니다.

stack ← [(start, null)]
while stack is not empty:
  current, parent ← pop(stack)
  if current is visited: continue
  방문 표시하고 부모 확정
  if current == goal: return 경로 복원
  미방문 이웃과 current를 역순으로 push
MODEL / 체스를 그래프로

64개의 칸이 정점이 된다면?

빈 칸은 정점(V), 한 번의 합법적인 기물 이동은 간선(E)입니다. 룩이 7칸을 가도 한 수이며, 장애물은 통과하거나 착지할 수 없습니다. 나이트는 중간 장애물을 뛰어넘습니다.

목표를 꺼내면 탐색을 종료하고, 부모 칸을 따라 경로를 복원합니다. BFS는 발견 시, DFS는 처음 꺼내 방문할 때 부모를 확정합니다. 대기 노드가 남아 있어도 성공입니다. 대기열이 비도록 목표를 못 찾으면 도달 불가입니다.

탐색 시간은 O(V + E)입니다. 탐색용 공간은 BFS O(V), 중복 후보를 넣는 이 DFS 구현은 O(V + E)입니다. 화면 기록·중복 제거 표시 비용은 별도입니다.

기물 이동 규칙 · 탐색 순서 · 사용 방법 자세히 보기
♚ 킹가로·세로·대각선으로 1칸. 도착 칸이 비어 있으면 이동합니다. 대각선 양옆의 장애물은 이동을 막지 않습니다.
♛ 퀸가로·세로·대각선으로 원하는 만큼 이동합니다. 장애물 직전에서 멈춥니다.
♜ 룩가로·세로로 원하는 만큼 이동합니다. 장애물을 넘어갈 수 없습니다.
♝ 비숍대각선으로 원하는 만큼 이동합니다. 장애물을 넘어갈 수 없고, 시작과 다른 색의 칸에는 도달할 수 없습니다.
♞ 나이트한 축으로 2칸, 다른 축으로 1칸(L자) 이동합니다. 중간의 장애물은 넘지만 장애물 칸에 착지할 수 없습니다.
♟ 폰백 폰으로 가정합니다. 위쪽(숫자가 커지는 방향)으로 1칸, 2행에서는 앞의 두 칸이 모두 비어 있으면 2칸도 가능합니다. 대각선 잡기·후진·승격은 없으며 8행에서는 더 이동하지 않습니다.

실험 범위 · 실제 대국 전체를 재현하지 않습니다. 상대 기물·포획·체크·체크메이트·캐슬링·앙파상·승격은 제외합니다. 장애물은 잡을 수 없는 고정된 벽입니다.

같은 결과 재현 · 이웃 칸은 a8 → b8 → … → h1 순으로 정렬합니다. BFS는 이 순서로 큐에, DFS는 역순으로 스택에 넣습니다. BFS는 넣는 순간 발견 표시하여 중복을 막습니다. DFS는 꺼낼 때 방문을 확정하고 이미 방문한 후보를 건너뜁니다. DFS의 내부 스택에는 중복 후보가 들어갈 수 있으며, 화면의 대기 목록과 최대 대기 수는 아직 방문하지 않은 칸을 중복 없이 셉니다. 발견 수는 한 번이라도 대기 후보로 들어간 서로 다른 칸 수입니다. 방문 숫자는 처리 순서이며 이동 횟수가 아닙니다.

사용 방법 · 기물과 알고리즘을 고르고, 시작·목표 선택 상자 또는 편집 모드와 체스판 클릭으로 배치합니다. 장애물 모드는 클릭할 때마다 추가/제거합니다. 방향키로 체스판 칸을 옮기고 Enter/Space로 편집할 수 있습니다. 시작=목표도 허용하며 이때 0회 이동입니다. 설정을 바꾸면 탐색 기록은 초기화됩니다.

화면 읽기 · 보라색 숫자는 방문 순서, 파란 칸은 대기, 노란 테두리·점은 현재 칸, 초록 선·작은 숫자는 최종 경로와 이동 순서(시작=0)입니다. 연결선은 착지 칸 사이의 이동을 나타내며 중간 칸을 방문했다는 뜻이 아닙니다. ‘시작 칸에서 가능한 이동’은 원으로 표시합니다.
